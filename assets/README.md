# Assets

Source vector artwork, icon masters, preview imagery, and template resources for **Windows Game Explorer**.

## Contents

| File | Description |
| --- | --- |
| `game-explorer-icon.png` | Fluent 3D controller icon master (256x256) with colored action buttons (Y=Yellow, B=Red, X=Blue, A=Green) and clean silhouette. |
| `game-explorer.ico` | Multi-resolution Windows icon (16, 20, 24, 32, 48, 64, 128, 256 px) embedded in `GameExplorerShell.dll` and `GameExplorerStudio.exe`. |
| `game-explorer-icon-win10.png` | Flat monochrome gamepad icon master (256x256) formatted for flat/monochrome Windows styles. |
| `game-explorer-icon-alt.ico` | Flat monochrome multi-resolution Windows icon (16, 20, 24, 32, 48, 64, 128, 256 px). Alternate optional icon for users who desire it. |
| `preview.png` | 16:9 banner preview artwork showing the File Explorer Games library view and Library Overview sidepane. |
| `preview-details.png` | Preview screenshot showing the File Explorer Games view with the Inspector Details sidepane active (box art, metadata, launch button, and achievements). |
| `preview-notifications.png` | Preview screenshot showing the File Explorer Games view with the in-view notification bell flyout (alerts, giveaways, and store news). |
| `preview-studio-library.png` | Preview screenshot showing Game Explorer Studio's Library Manager page (installed/custom games list, game properties editor, and online artwork discovery gallery). |
| `preview-studio-catalogue.png` | Preview screenshot showing Game Explorer Studio's Game Catalogue page (owned games list across storefronts, multi-source filters, and owned editions inspector). |
| `roms-template/` | Directory template defining clean, pre-structured ROM collection folders across 20+ console systems. |
